## 1. 圖框高度、欄寬 ✅

圖框高度一律由寬度推算(CSS `aspect-ratio`),不用 `object-fit` 湊比例:

```math
h_{\text{img}} = \frac{w}{r}
```

**section 的欄**(電腦結構,12 欄格線,第 $j$ 欄佔 $c_j$ 格,共 $n$ 欄):

```math
w_j = \bigl(W - g\,(n-1)\bigr)\cdot\frac{c_j}{12}
```

**格線的卡片**($c$ 欄)與**輪播的卡片**(一次顯示 $p$ 張,$p$ 可以是小數,例如 1.2 張):

```math
w_{\text{card}} = \frac{W - g\,(c-1)}{c},
\qquad
w_{\text{carousel}} = \frac{W - g\,(\lceil p\rceil - 1)}{p}
```

**平板的欄數**由電腦推算,但不少於手機:

```math
c_{\text{tablet}} = \max\bigl(c_{\text{desktop}} - 1,\; c_{\text{mobile}}\bigr)
```

- 程式:`src/model/responsive.ts`、`poc/estimate-vs-render/model.ts`(`blockWidth`)、`estimate.ts`。
- 已知限制:平板推算偏保守(見[發現與型式限制](../wiki/發現與型式限制.md)),💡 可改為依卡片寬度的範圍反推欄數。

## 2. 字寬與標題行數 ✅

每個字元依類別給寬度(em):

```math
e(\text{ch}) =
\begin{cases}
1 & \text{CJK（全形）}\\
0.3 & \text{半形標點與空白}\\
0.55 & \text{其他英數字}
\end{cases}
```

半形標點的 0.3 是 POC 1 實測後加上的。第一輪把它當成英數字,標題多估一行,區塊誤差最大 13.8%。

**比例法**(規格的公式):

```math
L_{\text{ratio}} = \max\!\left(1,\; \left\lceil \frac{s \sum_{k} e(\text{ch}_k)}{w} \right\rceil\right)
```

**逐字排入**(貪婪斷行):把標題切成不可拆的單位,英數字串是一個單位,中文一字一個。一個一個放進目前這一行,放不下就換行:

```text
lines ← 1, used ← 0
for 每個單位 t(寬度 w_t):
    if used + w_t > w 且 used > 0: lines ← lines + 1, used ← w_t
    else: used ← used + w_t
```

- 選貪婪法而不是 Knuth–Plass(TeX 的最佳斷行),是因為**瀏覽器本身就用貪婪法斷行**;要預測瀏覽器,就要用同一種算法。
- 結果:78 筆量測中,逐字排入 100% 正確,比例法 99.2%。
- 程式:`poc/estimate-vs-render/text.ts`。

## 3. 區塊高度與估算誤差 ✅

**卡片**(圖上文下):圖 + 圖文間距 + 標題 + 作者 + 摘要 + 下內距:

```math
H_{\text{card}} = \frac{w}{r} + \gamma + L\,s\,\lambda + A + S + \pi
```

其中作者列 $A = 4 + 14\lambda$(有作者時),摘要 $S = 4 + L_s \cdot 16\lambda$(有摘要且型的文字量不是只有標題時),否則為 0。

**格線**:每列取最高的卡片,列與列之間夾列間距,再加區塊標題列:

```math
H_{\text{grid}} = h_0 + \sum_{q=1}^{R} \max_{i \in \text{row}_q} H_{\text{card},i} + (R-1)\,\rho,
\qquad R = \left\lceil \frac{n}{c} \right\rceil
```

**左圖右文清單**(縮圖佔寬 $\tau$,手機結構 1/3、電腦結構 1/4;排行有名次時再扣名次欄 32px 與一個欄距):

```math
H_{\text{side}} = h_0 + \sum_{i=1}^{n} \max\!\left(\frac{\tau W}{r},\; T_i\right) + (n-1)\,\iota,
\qquad
w_{\text{text}} = W - \tau W - g - [\text{numbered}]\,(32 + g)
```

**首則與清單左右並排**:兩欄取較高者,兩欄的高度另外記下,給欄底對齊用。

**估算誤差**:

```math
\varepsilon = \frac{\lvert \hat H - H_{\text{measured}} \rvert}{H_{\text{measured}}}
```

POC 1:範例首頁 78 筆的中位數與最大值都是 0.0%;產生器的版面最大 0.02%。

- 程式:`poc/estimate-vs-render/estimate.ts`;驗收:`npm run poc:1`。

## 4. 判定函數與門檻 ✅

每個項目把量到的數字 $x$ 換成合格、警告或不合格。**越小越好**的項目有一般標準 $a$ 與上限 $b$:

```math
v(x) =
\begin{cases}
\text{pass} & x \le a\\
\text{warn} & a < x \le b\\
\text{fail} & x > b
\end{cases}
```

越大越好的項目方向相反。主要項目的量法:

| 項目 | 量法 | 合格 | 警告 |
| --- | --- | --- | --- |
| 區塊長度(手機) | $x = H / V_h$ | $\le 1.5$ 屏 | $\le 2$ 屏 |
| 欄高、欄底對齊 | $\delta = \dfrac{H_{\max} - H_{\min}}{H_{\max}}$ | $\le 5\%$ | $\le 10\%$ |
| 填充率 | $f = \dfrac{\text{文字區高}}{\text{圖高}}$ | $0.6 \le f \le 0.9$ | 其他 |
| 末列不落單 | $m = n \bmod c$ | $m = 0$ | $m \ge c/2$ |

末列不落單在 $0 < m < c/2$ 時不合格。

- 程式:`poc/evaluate/checks.ts`、`evaluate.ts`;門檻來自 `template-evaluation`、`page-evaluation`。

## 5. 最差寬度、面向分數、總分 ✅

同一個對象在 6 種測試寬度 $\mathcal{W}$ 各量一次,報告取**最差的那個寬度**:

```math
x^{*} = \max_{w \in \mathcal{W}} x(w)
\quad\text{（越大越差的項目；越小越差的取 min）}
```

**面向分數**:和 Lighthouse 一樣,一個項目只扣一次(取所有對象中最差的判定),分數不因區塊多而放大。

```math
S_f = \max\!\Bigl(0,\; 100 - \sum_{i \in f} p(v_i)\Bigr),
\qquad
p(\text{pass}) = 0,\; p(\text{warn}) = 10,\; p(\text{fail}) = 30
```

**總分**是有分數的面向的平均,四捨五入:

```math
T = \operatorname{round}\!\left(\frac{1}{\lvert F \rvert}\sum_{f \in F} S_f\right)
```

**整頁判定**:任一項目不合格,或 3 個以上項目警告,即不合格。

- 程式:`poc/evaluate/evaluate.ts`(`scoreFindings`、`mergeWorst`)。
- 扣分 30 / 10 是先訂的值。🔜 第 14 節要用人評資料學出權重。

## 6. 目標函數、貪婪法、集束搜尋 ✅

產生器與改進建議要比較兩個版面誰比較好。只用總分 $T$ 時,很多版面同分,也分不出欄高差 60% 和差 15%。所以目標函數再加三項:

```math
J = 1000\,T \;-\; 10\,N_{\text{fail}} \;-\; N_{\text{warn}} \;-\; 100 \sum_{k \in \text{欄高、欄底對齊}} \delta_k
```

- $N_{\text{fail}}$、$N_{\text{warn}}$ 是對象層級的件數(不是項目層級),用來在同分時偏好問題較少的版面。
- 違反第 1 層規則的版面,$J = -\infty$。

**貪婪法(逐塊座標上升)**:每一輪依序走過每一塊 $i$,在它的選項 $O_i$ 中選讓 $J$ 最大的一個;直到一整輪都沒有改善為止。

```math
o_i \leftarrow \arg\max_{o \in O_i} J(o_1, \dots, o_{i-1}, o, o_{i+1}, \dots)
```

**集束搜尋**:依序決定每一塊,每一步只保留目標函數最高的 $k$ 個部分解(預設 $k=3$)。同分時保留先展開的,所以結果是確定性的。

- 一組參數約試算 350~420 種組合。
- 程式:`poc/generator/generate.ts`、`poc/examples/greedy.ts`。
- 第 5 階段的規格是「只對前 3 名渲染驗證」,這也是公式試算與渲染之間的分工。

## 7. 人評對齊的基本量 ✅

**區塊的程式分數**(換成和人評一樣的 0~10):$F$、$W$ 是這塊不合格、警告的項目數,一個項目只算一次。

```math
s_{\text{prog}} = \max(0,\; 10 - 3F - W)
```

**等級相關**(Spearman):先把兩組分數換成名次,同分取平均名次,再算 Pearson 相關:

```math
\rho = \frac{\operatorname{cov}\bigl(R(x), R(y)\bigr)}{\sigma_{R(x)}\,\sigma_{R(y)}}
```

**A/B 一致率**:程式總分較高的那一版,評分者也選它的比例。不計「差不多」與程式同分的題目:

```math
a = \frac{\#\{\text{評分者選的} = \text{程式選的}\}}{\#\{\text{有分出勝負的題目}\}}
```

**盲點與可能的誤判**:人評比程式低 $\Delta$ 分以上是盲點,高 $\Delta$ 分以上是可能的誤判,$\Delta = 3$。

**覆蓋率**:「不喜歡」的短評中,對應的項目在報告裡**確實有問題**的比例。同一塊剛好有別的問題,不算覆蓋。

```math
C = \frac{\#\{\text{dislike} : \text{對應項目在同一對象上不合格或警告}\}}{\#\{\text{dislike}\}}
```

- 目前的數字:前 8 個角色 $a = 57/75 = 76\%$,加上新角色後 $73/93 = 78\%$;$\rho \in [-0.18,\ 0.28]$;$C = 10/33 = 30\%$。
- 程式:`poc/rating/collect.ts`、`analyze.ts`、`align.ts`、`poc/feedback/coverage.ts`。

## 8. 比例的信賴區間 🔜

一致率 76% 是 75 題算出來的,要附上範圍,才知道下一輪的變化是不是真的。樣本不大時,用 Wilson 區間:

```math
\tilde p = \frac{\hat p + \frac{z^2}{2n}}{1 + \frac{z^2}{n}},
\qquad
\text{半寬} = \frac{z}{1 + \frac{z^2}{n}}\sqrt{\frac{\hat p(1-\hat p)}{n} + \frac{z^2}{4n^2}}
```

**套在現有資料**:$57/75$ 的 95% 區間($z = 1.96$)是 **65.2% ~ 84.2%**。

**計畫**:`poc:align` 的 A/B 一致率與 `poc:feedback` 的覆蓋率都附上區間;兩輪比較時,區間不重疊才說有進步。

## 9. 再測信度、最小可偵測變化 🔜

同一位評分者對同一個沒改過的版面評兩次,差 $d = x_2 - x_1$。單次評分的測量誤差:

```math
\text{SEM} = \frac{\sigma_d}{\sqrt 2},
\qquad
\text{MDC}_{95} = 1.96\,\sqrt 2\;\text{SEM} = 1.96\,\sigma_d
```

$m$ 位評分者取平均時,約為 $\text{MDC}_{95}/\sqrt m$。

**套在現有資料**:第一、二輪中沒改過的 11 塊 × 8 個角色,共 88 對。

| 量 | 值 |
| --- | --- |
| 差的平均 | −0.06 |
| $\sigma_d$ | 0.75 |
| 兩次完全相同 | 61% |
| 相差 1 分以內 | 94% |
| 單一角色的 $\text{MDC}_{95}$ | **1.47 分** |
| 8 個角色平均的 $\text{MDC}_{95}$ | **0.52 分** |

**這回答了兩個問題**:

1. 盲點門檻 $\Delta = 3$ 遠大於單一角色的雜訊 1.47 分,門檻是合理的。
2. 修正渲染器後,D 升 0.38 分、K 升 0.25 分,都**小於 0.52 分**,統計上不能說有改善。這和短評的解讀一致:主因不是這兩個 bug。

**計畫**:`poc:align` 在有兩輪資料時自動算出這張表;真人評分也照做。

## 10. 評分者間一致性 🔜

不同評分者對同一塊的看法有多一致。分數是等距尺度時,用 ICC(2,1)(雙向隨機效果、單一評分者):

```math
\text{ICC}(2,1) = \frac{\text{MS}_R - \text{MS}_E}{\text{MS}_R + (k-1)\,\text{MS}_E + \frac{k}{n}\bigl(\text{MS}_C - \text{MS}_E\bigr)}
```

$\text{MS}_R$、$\text{MS}_C$、$\text{MS}_E$ 是區塊、評分者與誤差的均方,$k$ 位評分者、$n$ 塊。資料有缺漏、或尺度不同(名目、順序、等距)時,用 Krippendorff's α:

```math
\alpha = 1 - \frac{D_o}{D_e}
```

$D_o$ 是觀察到的不一致,$D_e$ 是隨機情況下預期的不一致。

**計畫**:

- 分別算「AI 角色之間」「真人之間」「AI 與真人之間」的一致性。
- 真人之間都不一致的塊,不拿來校正評估器。
- AI 角色和真人一致性低的項目,不再用 AI 角色篩盲點。

## 11. 圈選區域的重疊與鄰近 🔜

圈選區 $R$ 與元素框 $B$(區塊、單則或元素)的兩種重疊比例:

```math
o_R(B) = \frac{\lvert R \cap B \rvert}{\lvert R \rvert}
\quad\text{（圈選區有多少落在 B）},
\qquad
o_B(B) = \frac{\lvert R \cap B \rvert}{\lvert B \rvert}
\quad\text{（B 有多少被圈到）}
```

- **目標**:$B^{*} = \arg\max_B o_R(B)$,且 $o_R(B^{*}) \ge 0.5$。依區塊、單則、元素三層各算一次,取最小的那一層。
- **圈到空白**(沒有元素的 $o_R \ge 0.5$):找包住 $R$ 的最小容器(區塊、欄、頁面),決定是哪一種空白;再以邊與邊的距離找上下左右最近的元素當鄰居。
- **跨好幾塊**:列出 $o_R(B) \ge 0.2$ 的所有 $B$,以 $o_R$ 當權重。

## 12. JAR 量表的懲罰分析 🔜

感官評估的標準做法:每條軸把評價分成「太少、剛好、太多」三組,看不在「剛好」時整體喜好掉多少。對軸 $a$ 的「太多」那一側:

```math
\text{drop}_a^{+} = \bar L_{\text{JAR}} - \bar L_{a}^{+},
\qquad
\text{penalty}_a^{+} = \text{drop}_a^{+} \times \frac{n_a^{+}}{n}
```

$\bar L$ 是整體喜好(0~10)的平均,$n_a^{+}/n$ 是說「太多」的比例。慣例上,比例達 20% 以上才當成問題。

**計畫**:受訓評估員(或真人)給各軸的值,讀者角色給整體喜好。懲罰最大的軸先改。例如「空 ↔ 擠」的「太空」懲罰最大,就先處理留白,再處理圖文比。

## 13. 找「剛好」的位置 🔜

每筆方向型評價 $y \in [-5, 5]$ 都配著當時量到的數字 $x$(例如留白比例)。「剛好」就是 $y$ 由負轉正的地方。

**線性**:

```math
y = \beta_0 + \beta_1 x + \varepsilon,
\qquad
x^{*} = -\frac{\beta_0}{\beta_1}
```

**單調迴歸**:只假設 $y$ 隨 $x$ 單調變化,不假設是直線。用 PAVA(相鄰違反者合併)演算法求出最接近資料的單調函數 $\hat y$,再取 $\hat y = 0$ 的位置。算法本身是確定性的:

```math
\hat y = \arg\min_{\,z_1 \le z_2 \le \dots \le z_n} \sum_{i} (y_i - z_i)^2
```

**計畫**:

- 依展示類型分開算(輪播本來就該圖多)。
- 求出的 $x^{*}$ 前後各一段當合格範圍,取代規格裡猜的門檻,例如填充率 60%~90%。

## 14. Bradley–Terry 模型與權重學習 🔜

**兩兩比較**:每個版面有一個強度 $\theta$,A 勝過 B 的機率是:

```math
P(A \succ B) = \frac{e^{\theta_A}}{e^{\theta_A} + e^{\theta_B}} = \sigma(\theta_A - \theta_B)
```

可以用 MM 演算法求最大概似解($\pi = e^{\theta}$,$W_i$ 是 $i$ 的勝場數,$n_{ij}$ 是 $i$、$j$ 比過的次數)。固定起點與迭代次數,結果就是確定性的:

```math
\pi_i^{(t+1)} = \frac{W_i}{\sum_{j \ne i} \dfrac{n_{ij}}{\pi_i^{(t)} + \pi_j^{(t)}}}
```

**學出項目權重**:讓強度由評估結果決定,$\theta = \mathbf w^{\top}\mathbf x$。$\mathbf x$ 是各項目的判定或量到的數字。那麼每一題 A/B 就是一筆邏輯迴歸資料:

```math
P(A \succ B) = \sigma\!\bigl(\mathbf w^{\top}(\mathbf x_A - \mathbf x_B)\bigr),
\qquad
\hat{\mathbf w} = \arg\min_{\mathbf w} \; -\sum \log P + \frac{\mu}{2}\lVert \mathbf w \rVert^2
```

**計畫**:

- 用 A/B 與「這樣會不會更好」的選擇學出 $\hat{\mathbf w}$,取代第 5 節固定的扣分 30 / 10。
- 範例 07 這類衝突,例如「整頁則數」對「看得見的留白」,會直接反映在兩者權重的大小。
- 加入 L2 正則化($\mu$),避免資料少時權重亂跳;改權重前要經過使用者確認。

## 15. 建議排序:偏差 × 確認率 🔜

使用者圈下區域時,對每個適用的維度 $d$ 算一個分數,取前 3~5 名:

```math
\text{score}(d) = z_d \cdot \hat q_d,
\qquad
z_d = \frac{\lvert x_d - x_d^{*} \rvert}{\sigma_d},
\qquad
\hat q_d = \frac{k_d + 1}{n_d + 2}
```

- $z_d$ 是量到的數字離「剛好」多遠(以標準差為單位)。
- $\hat q_d$ 是同類情況下,這個維度被確認的比例($k_d$ 次確認、$n_d$ 次顯示)。加 1、加 2 是拉普拉斯平滑,也就是 Beta(1,1) 先驗的後驗平均:沒有資料時是 0.5,不會因為一兩次就變成 0 或 1。

**評估指標**:前 $k$ 名命中率 $= \#\{\text{使用者選的在前 } k \text{ 名}\} / \#\{\text{圈選}\}$。

## 16. 資訊增益選題 🔜

適應性提問的每一輪,從候選題目中選最能縮小「他想說的是什麼」範圍的題目。設 $C$ 是候選原因的分布:

```math
H(C) = -\sum_{c} P(c)\log_2 P(c),
\qquad
\text{IG}(q) = H(C) - \sum_{a} P(a \mid q)\, H(C \mid q, a)
```

**計畫**:

- 每一輪取 IG 最大的 3 題,但限制 3 題落在維度樹的不同分支。
- $H(C)$ 低於門檻,或已經問了 3 輪,就停止。
- $P(c)$ 一開始用第 15 節的分數正規化;有資料後用歷史的確認次數。

## 17. Lighthouse 式的連續計分曲線 💡

現在的扣分是階梯式的(合格 0、警告 10、不合格 30)。Lighthouse 對連續的量用對數常態曲線:在中位數 $m$ 得 0.5 分,在 $p_{10}$ 得 0.9 分。

```math
\text{score}(x) = 1 - \Phi\!\left(\frac{\ln x - \ln m}{\sigma}\right),
\qquad
\sigma = \frac{\ln m - \ln p_{10}}{\Phi^{-1}(0.9)}
```

**為什麼值得考慮**:POC 3 發現產生器分不出「欄高差 60%」和「差 15%」,因為兩者都是不合格。只好在目標函數另外加上欄高差(第 6 節)。連續計分讓差一點和差很多分得開,搜尋就有方向。$m$ 與 $p_{10}$ 可以由第 13 節的資料定出。

## 18. 欄高平衡 = 分割問題 💡

一個 section 有兩欄,要把區塊分到兩欄,讓兩欄的高度差最小:

```math
\min_{S \subseteq B} \;\Bigl\lvert \sum_{i \in S} h_i - \sum_{i \notin S} h_i \Bigr\rvert
```

這是經典的**分割問題**(NP 困難)。但區塊數少、高度可以取整數,用動態規劃就能求出精確解,時間與「區塊數 × 總高」成正比。

**計畫**:用在「把較高那欄的一塊移到另一欄」的建議,直接算出最好的分法,不用逐一試。若區塊順序有限制(例如頭條必須在最上面),就加成動態規劃的條件。

## 19. 版面平衡的力矩 💡

把每塊看成重量等於面積 $a_i$(可再乘上視覺份量)的物體,算整頁左右(或上下)的力矩是否平衡:

```math
B_x = 1 - \frac{\bigl\lvert \sum_i a_i (x_i - x_c) \bigr\rvert}{\sum_i a_i \cdot \frac{W}{2}}
```

$x_i$ 是第 $i$ 塊的中心,$x_c$ 是頁面中線;$B_x = 1$ 是完全平衡。這是計算美學文獻中常見的版面指標之一。

**計畫**:做為「平衡」面向的候選項目,先和人評比對,確認有用再加。

## 20. 型式多樣性(熵) 💡

AI 角色與 POC 3 都發現:產生器偏好單調的 P07,整頁 4 塊都是同款網格。用展示類型的使用比例 $p_k$ 算正規化的熵:

```math
D = \frac{-\sum_{k} p_k \log p_k}{\log K}
```

$D = 0$ 是整頁只用一種型;$D = 1$ 是 $K$ 種型平均使用。

**計畫**:做為「節奏」面向的候選項目;門檻同樣由人評資料決定。

## 21. 項目反應理論 💡

把適應性提問當成測驗:受試者有一個隱藏的傾向 $\theta$(例如對留白的容忍度),每一題有鑑別度 $a$ 與難度 $b_k$。分級反應模型:

```math
P(Y \ge k \mid \theta) = \sigma\bigl(a(\theta - b_k)\bigr)
```

**用途**:題目累積夠多以後,估出每一題的鑑別度,優先問鑑別度高的題目;也能把不同人的回答放在同一個尺度上比較。

## 22. 偏好式貝氏最佳化 💡

「這樣會不會更好」的參數是連續的時候(例如縮圖比例 0.18~0.30、間距 8~24px),用高斯過程對偏好建模,每次挑最有可能更好、又最不確定的下一組參數給人比較。相關方法:Sequential Line Search(使用者只拉一條滑桿,系統依偏好調整下一條線的方向)。

**用途**:比逐一試「1/4、1/5、1/6」收斂得快。需要亂數的地方固定種子。

## 23. 主動學習:挑最有資訊的 A/B 題 💡

真人評分有限。用第 14 節的模型預測每一題的 $P(A \succ B)$,優先問**最接近 0.5** 的題目,也就是模型最不確定的題目:

```math
q^{*} = \arg\min_{q} \bigl\lvert P_q(A \succ B) - 0.5 \bigr\rvert
```

模型已經很確定的題目(例如範例 03、04,8 個角色全部同意),再問也學不到東西。
