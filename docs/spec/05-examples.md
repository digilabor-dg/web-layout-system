# 評估實例

結構對稱的型天生平衡,要靠評估調參的是不對稱的型(如 08、09、11、14、21)。以下三例取自版型圖鑑的截圖,數字依截圖粗估。

## 問題類型對照表

問題類型與評估數值可以互算:類型→數值是需求反饋,把人的感覺翻成指標與目標;數值→類型是決策,依量到的數字判定問題。兩個方向用同一張表。

| 問題類型 | 常見說法 | 指標 | 目標 | 候選改法 |
| --- | --- | --- | --- | --- |
| 密度不足 | 「右邊太空」「看起來很空」 | 文字區高 ÷ 並排圖片高(填充率) | 60%\~90% | 提高內文等級、加 META、加相關連結、嵌入重點整理、調左右比例 |
| 欄底不齊 | 「左右不平」「一邊太長」 | 並排兩欄底邊差 ÷ 較高欄 | 一般 ≤ 5%,上限 10% | 調內文等級、調左右比例、換型 |
| 列距太擠 | 「黏在一起」 | 卡片間距 ÷ 卡片內圖文距 | ≥ 2 倍 | 加大列距 |
| 密度過高 | 「太擠」「字太多」 | 手機上區塊高 ÷ 螢幕高 | ≤ 1.5 屏 | 降內文等級、改輪播、減則數 |
| 層級不清 | 「看不到重點」 | 頭條圖高佔手機首屏比、相鄰放大型數 | ≤ 40%,放大型不相鄰 | 換型、減少放大型 |

## 實例一:型 14 右邊太空

> 示意:左側 3:2 圖片;右側文字區只佔圖高約 25%,上下各留一大塊空白。

左側圖片高約 680px,右側文字區約 170px,填充率約 25%,低於 60%,判定為「密度不足」。

| 改法 | 預估高度變化 |
| --- | --- |
| 內文等級 3 → 6 | 約 +150px |
| 加 META(作者、日期、專題篇數) | 約 +25px |
| 加 3 條專題內文章連結 | 約 +90px |
| 嵌入型 36 重點整理(3 點) | 約 +80px |
| 左右比例 7:5 改 6:6 | 圖高約 −100px |

組合如「內文 3 → 5 + 加 3 條連結」可落在 60%\~90%。單一區塊選項少,直接試算即可。

## 實例二:型 08 欄底不齊、列距太擠

> 示意:左欄為大圖 + 標題 + 3 行內文;右欄 2×2 小卡只有圖和標題,底部比左欄短約 38%,上下排小卡幾乎貼在一起。

左欄約 920px、右欄約 570px,高度差約 38%,「欄底不齊」不合格;上排小卡標題與下排圖片幾乎貼在一起,「列距太擠」警告。圖上的箭頭就是兩個調整方向:左欄往上收,右欄往下長。

| 改法 | 效果 | 是否合法 |
| --- | --- | --- |
| 小卡內文 0 → 2 | 右欄約 +100px | 合法,小卡上限 2 級 |
| 主則內文 3 → 1 | 左欄約 −70px | 合法 |
| 左右比例 8:4 → 7:5 | 左圖變矮、右卡變高,兩邊同時靠近 | 合法 |
| 右側加成 3 列 | 則數變 7,超出型 08 的 5 則 | 不合法,排除 |
| 換成型 09 | 右側清單長度可隨左欄調整 | 跨型,由人決定 |
| 卡片列距 12px → 24px | 解決列距太擠 | 合法 |

單一改法都不夠,要組合,例如「7:5 + 小卡內文 1 + 主則內文 2 + 列距 24px」;找出這種組合就是試算或仿生搜尋的工作。

## 實例三:型 10 對稱結構天生平衡

> 示意:左右兩半各為大圖 + 2 行內文 + 2 張小卡,結構相同,底線同高。

左半(大圖 + 下方 2 張小卡)與右半結構相同,高度天生相等,欄底差 0%,直接合格。這類型不必調參,評估只需確認內文等級左右一致。
