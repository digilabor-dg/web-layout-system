# 資料模型

> 白話說明 [`site-profile`](../../openspec/specs/site-profile/spec.md)、[`layout-patterns`](../../openspec/specs/layout-patterns/spec.md)、[`content-model`](../../openspec/specs/content-model/spec.md)、[`image-ratio-policy`](../../openspec/specs/image-ratio-policy/spec.md)、[`block-composition`](../../openspec/specs/block-composition/spec.md)、[`page-layout`](../../openspec/specs/page-layout/spec.md)、[`sample-data`](../../openspec/specs/sample-data/spec.md)。條文以 spec 為準,本頁只負責講清楚。
>
> 狀態:✅ 第 1 階段已實作。

一個頁面怎麼排,全部寫成 JSON。資料分成 9 種,由大到小是:

```
網站設定(全站一份)
  └ 約束 → 區塊範本 = 內容類型 + 展示類型 + 選稿規則
                         └ 放到頁面上 → 區塊實例(版位)→ 放入新聞則
```

## 網站設定:全站只有一份

決定整個網站的「物理規則」,範本和實例都不能改它。

- **媒體類型決定主比例**:平面媒體 3:2,影視媒體 16:9,二選一。1:1 一律可以用。
- **裝置分 4 類**:手機、直立平板、橫放平板、電腦。斷點從預設參數組來:
  - **bs5**(Bootstrap 5):平板 768、橫放平板 992、電腦 1200。範例站用這組。
  - **tw4**(Tailwind 4):768、1024、1280。
  - **md3**(Material Design 3):600、840、1200。
  - 只取框架的「數字」,不用框架的程式碼;網站可以逐項覆寫。
- **主切換點**是橫放平板的起點(bs5 為 992px):以下用手機排法(上下堆疊),以上用電腦排法(左右並排)。
- **測試寬度固定 6 種**:360、390、768、1024、1280、1440,三組預設參數組都把它們分到同樣的裝置類別。
- **字級、行高、字寬、間距**:估算高度用的數字,目前是示意值,之後用實測校正。

## 展示類型:區塊「怎麼排」,與內容無關

共 38 種(上限 40),例如「P09 首 1 則放大,其餘純文字」。每種用 7 個屬性描述:

| 屬性 | 例子 |
| --- | --- |
| 排列 | 單一、清單、網格、拼貼、輪播、分頁 |
| 強調 | 無、首 1 則放大、首 2 則放大 |
| 圖文關係 | 圖上文下、左圖右文、疊字、無圖 |
| 文字量 | 只有標題、標題加摘要、段落 |
| 圖片 | 每個位置允許哪些圖片角色 |
| 則數範圍 | 例如 P09 是 4~6 則;「不限」寫成沒有上限 |
| 互動 | 無、輪播、分頁籤、跑馬燈、播放、展開、投票 |

- **新型還是變體**:只有排列、互動或內容結構不同才算新型;只差欄數、則數、比例或文字量,算同一型的變體。
- **標籤與分組只用來找型**:外觀標籤(圖、文、混合、輪播、放大)一型可以有多個;用途分組(新聞組合、影音、數據、文字為主、互動)一型只屬一組。
- **響應式只存手機與電腦**,平板由程式推算:電腦欄數減一,但不少於手機欄數。型 21~38 的排法還沒定義,先留空。

## 內容類型與新聞則:區塊「放什麼」

- **7 種內容類型**:新聞、快訊、影音、觀點、圖表、專題、推廣。政治、財經這類分類是新聞的子屬性。
- 每種內容類型有**建議搭配的展示類型**;不在建議內的組合不會被擋,只會警告。
- **每則新聞**有標題、網址、發布時間,以及依「圖片角色」各存一份裁好的圖:
  - `main`(主比例)與 `square`(1:1)每則都要有。
  - 影音這類需要 16:9 縮圖的內容,另外要有 `video`。
  - 每份圖都記錄裁好後的寬高。
- **標題字數不另存**,需要時從標題算。
- 範例資料一律用示意文字,不放真實客戶資料。

## 圖片比例規範

- 只用主比例、1:1,以及影片的 16:9;**禁止直式圖**。
- 圖在後端裁好;前端用 CSS `aspect-ratio` 預留圖框,不用 `object-fit` 的 contain 或 cover 湊比例。
- 圖檔的寬高比和應有比例相差不能超過 1%。

## 區塊範本與實例

- **範本**是可重複使用的規格,組成是:用途(頭條、熱門、分類版區…)+ 內容類型 + 展示類型 + 則數 + 選稿規則 + 響應式 + 標題與「更多」連結。
  - 選稿規則有 4 種:編輯手選、自動最新、依熱門、混合(前幾則手選、其餘自動補)。
  - 展示類型允許兩種圖片角色時(例如 P03 可用主比例或 1:1),範本要選定一種。
  - 範本可以設定「斷點下換型」,例如頭條在手機改用另一型。
- **實例(版位)**是範本放到頁面上的那一份,填入實際新聞。
  - 只能覆寫則數、選稿規則、區塊標題,而且覆寫後的則數仍要在範圍內。
  - 實例不記自己在頁面的位置;位置只由頁面決定。
  - 可以設定在手機或電腦上隱藏整塊,但會被警告,因為規格要求「不在手機上藏稿」。

## 頁面與 section

- 頁面由上而下列出 **section**,每個 section 有兩種排法:
  - **stack**:宣告欄配置(例如 8:4),每欄由上而下堆疊區塊。主欄配側欄就用這種。
  - **flow**:每塊宣告佔幾欄,由左而右排,超過 12 欄就自然換列。
- **版位代號由位置算出來,不存在資料裡**:
  - `flat`:整頁 A~Z,則的代號是版位加序號,例如 H3。
  - `sectioned`:section 字母加區塊字母,例如 AC,則為 AC12。
  - 區塊之間的引用一律用 id,所以搬動區塊時代號會重排,但引用不會斷。
- **手機順序**:預設把各欄依序串成一欄;也可以指定順序,例如把側欄的熱門排行插到頭條後面。

## 範例資料

範例站是平面媒體、3:2、bs5、欄距 1rem。首頁有 4 個 section、13 個版位(A~M)、61 則,用到 9 種展示類型;C、D、K 放在側欄。範例資料必須通過第 1 層規則檢查,錯誤與警告都是 0。
