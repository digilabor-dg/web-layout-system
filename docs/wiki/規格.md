# 規格總覽

**規格的唯一依據是 [`openspec/specs/`](../../openspec/specs/)**。每個 capability 一份 `spec.md`,由 SHALL/MUST 條文與情境(WHEN/THEN)組成。wiki 用白話描述這些規格,分成 5 頁:

| 白話頁 | 涵蓋 |
| --- | --- |
| [資料模型](資料模型.md) | 網站設定、展示類型、內容類型、圖片比例、範本與實例、頁面與 section、範例資料 |
| [規則檢查](規則檢查.md) | 第 1 層 25 條規則、核心函式庫的界線 |
| [估算與渲染](估算與渲染.md) | 高度公式、HTML 渲染、6 種寬度量測 |
| [評估](評估.md) | 第 2、3 層項目、判定方式、8 個面向 |
| [改進與生成](改進與生成.md) | 候選改法與貪婪法、AI 的角色、版面生成 |

原始設計說明在 [`docs/spec/`](../spec/01-architecture.md),現在當作發想與資料收集。

```bash
openspec list --specs
```

```bash
openspec show rule-check --type spec
```

## 關鍵決定

完整紀錄見 [resolve-spec-ambiguities 的決策](../../openspec/changes/archive/2026-11-03-resolve-spec-ambiguities/design.md),以及 [搬移時補充的詮釋](../../openspec/changes/archive/2026-11-03-migrate-docs-to-openspec/design.md)。

| 主題 | 決定 |
| --- | --- |
| 圖片角色 | `main`(網站主比例)、`square`(1:1)、`video`(16:9)、`none`;依用途命名,不依比例 |
| 圖檔 | 每份存 `{ src, width, height }`;第 1 層檢查比例誤差 ≤ 1%、不得直式 |
| 二選一的圖片 | 展示類型列允許清單,範本以 `imageRole` 選定,實例不可覆寫 |
| section | 寫在 Page 裡;`stack`(主欄與側欄,各欄獨立堆疊)或 `flow`(依 span 自然換列) |
| 版位代號 | 由位置推算、不存資料;`flat`(H3)或 `sectioned`(AC12);引用一律用 id |
| 裝置 | 4 類:mobile、tablet-V、tablet-H、desktop;只設計手機與電腦,平板由程式推算 |
| 預設參數組 | bs5(範例站採用)、tw4、md3;主切換點 = tablet-H 起點 |
| 標題字數 | 不另存,從 `title` 計算 |
| 工作流程 | 一個開發階段 = 一個 change = 一個 PR;同時最多 5 個未 archive 的 change |
